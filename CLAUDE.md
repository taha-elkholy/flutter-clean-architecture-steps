# CLAUDE.md

Guidance for Claude Code when working in this repository.

See @.claude/project-context.md for what this project is and why it's
structured the way it is.

See @.claude/branch-rules.md for the strict rules on what a branch is
allowed to touch. Read this before making any change.

## The one rule that matters most

Never solve more than the current branch's stated problem. If something
looks messy but isn't what this branch is about, leave it — it's probably
the subject of a later branch on purpose.
